# অভিন্ন বিন্যাসকে চ্যালেঞ্জ করুন

**একটি ম্যাপ জমা দিন, যা গতি ও ঝড় দুই টাইপিং স্টাইলেই অপরিবর্তিত ব্যবহৃত হবে।** কালা লেআউট আপাতত রেফারেন্স। সিজন `bangla-dh-shared-challenge-v1`। [কেন অভিন্ন বিন্যাস?](SHARED_LAYOUT.md) লক্ষ্য ও খরচ ব্যাখ্যা করে।

## স্কোরার চালান

Python 3.10 বা নতুন, শুধু স্ট্যান্ডার্ড লাইব্রেরি। [স্কোরিং প্যাকেজ](../challenge/shared-v1/) একসঙ্গে রাখুন: স্ক্রিপ্ট, সংকুচিত গণনার তথ্য ও চলাচলের মডেলের লাইসেন্স। করপাস নামানো বা প্যাকেজ ইনস্টল লাগে না। প্যাকেজ প্রায় 3 MB; উন্নয়নের কম্পিউটারে দুই স্টাইলের প্রশিক্ষণ স্কোর সাধারণত এক সেকেন্ডের কমে হয়, এটি সময়ের নিশ্চয়তা নয়।

```bash
python challenge/shared-v1/score.py --reference
python challenge/shared-v1/score.py --template my-shared.json
python challenge/shared-v1/score.py my-shared.json --diagnostics
```

টেমপ্লেটের 26টি অক্ষর-কী বদলান; প্রতিটিতে base ও Shift প্রতীক। সিজন রাখুন; একটি স্টাইল বা স্টাইলভেদে আলাদা ম্যাপ দেবেন না। প্রতিটি নির্ধারিত প্রতীক একবার থাকতে হবে। অঙ্ক, যতিচিহ্ন, এনকোডার ও মডেলের ধ্রুবক স্থির। ডটেড সার্কেল ও ক্যানোনিক্যাল সমতুল্য বাংলা প্রতীক NFC-তে স্বাভাবিক করা হয়।

## যোগ্যতা ও তুলনা

মূল স্বতন্ত্রভাবে স্বাভাবিক করা 50/50 প্রশিক্ষণ-মিশ্রণ ও মডেল-অপটিমাল আঙুল-বিন্যাসে দুই স্টাইলকেই মানতে হবে:

* নির্ভুল ভগ্নাংশের J1 সেই স্টাইলের **আগের আলাদা বিন্যাসের** পরিশ্রমের সর্বোচ্চ 403/400 (+0.75%)।
* শব্দের ভেতরে একই আঙুলের ভিন্ন-কী দূরত্ব আগের রেফারেন্সের সর্বোচ্চ 1.075 (+7.5%), আগের 1e-14 পরম ছাড়সহ।

এটি শিথিল অভিন্ন নীতি, আগের কঠোর Balance নীতি নয়। কালা লেআউট-কে ভিত্তি করে সীমা আবার বাড়ানো হয়নি। স্পেসের ওপারের চলাচল বাড়তে পারে, কিন্তু তার জন্য স্কোরে ধনাত্মক জরিমানা থাকে। স্থির চার-উপাদানের সূত্র, প্রতি স্টাইলের 81টি অগ্রাধিকার সেটিং, স্কেল, লক্ষ্য, ক্যালিব্রেশনের নিম্নমান ও অসমর্থিত ক্রমের সীমা অপরিবর্তিত।

যোগ্য ম্যাপে গতি ও ঝড়ের আলাদা R থাকে; একই স্টাইলে কম ভালো। দুই স্টাইলের R যোগ, গড় বা সরাসরি তুলনা করা হয় না। কালা লেআউট-এর উন্নতি হতে হলে দুই R-এই খারাপ হওয়া চলবে না এবং অন্তত একটিতে ভালো হতে হবে। এক স্টাইলের কম J1 যথেষ্ট নয়। B02 একটি সমঝোতা, দুই স্কোরেই বিজয়ী নয়। তুলনায় রাউন্ড না করা ফল ব্যবহৃত হয়।

[অভিন্ন তালিকায়](../submissions/shared-v1/LEADERBOARD.md) আগে ফ্রন্টিয়ার, তারপর প্রভাবিত ও অযোগ্য বিন্যাস দেখায়। ফ্রন্টিয়ার কালা লেআউট ও সব যোগ্য জমার তুলনায় নির্ধারিত। একই দলের মধ্যে ফাইলের নাম প্রদর্শনের ক্রম ঠিক করে, সামগ্রিক র‍্যাঙ্ক নয়। একই স্বাভাবিক করা ম্যাপ দুই স্টাইল মিলিয়ে একবার গণনা হয়; আগে প্রক্রিয়া করা ফাইলের নাম রাখা হয়। সমান স্কোর-জোড়া সমান থাকে। রেফারেন্সের কপি ও পুনরাবৃত্ত জমা আলাদাভাবে জানানো হয়। স্কোর না বদলে লেখকত্বের বিরোধে রক্ষণাবেক্ষণকারীরা Git ইতিহাস দেখতে পারেন।

## জমা ও যাচাই

পুল রিকোয়েস্টে JSON ফাইল [submissions/shared-v1/](../submissions/shared-v1/)-এ যোগ করুন। যাচাইয়ে স্কোর আবার হিসাব হয়; ফাইলে লেখা স্কোরের দাবি উপেক্ষা করা হয়। ভুল গঠন বা অন্য সিজনের ফাইল ব্যর্থ হয়। বৈধ কিন্তু অযোগ্য ম্যাপ স্পষ্টভাবে চিহ্নিত হয় এবং যৌথ র‍্যাঙ্ক পায় না। বৈধ জমা নিজে থেকে কালা লেআউট প্রতিস্থাপন করে না।

```powershell
$env:PYTHONPATH = "src"
python -m bangla_dh challenge-verify my-shared.json
python -m bangla_dh leaderboard --check my-shared.json
```

প্রথম কমান্ড পোর্টেবল স্কোরকে স্বাধীন পূর্ণসংখ্যা/সরাসরি হিসাবের সঙ্গে মেলায়। স্বতন্ত্র স্কোরারের diagnostics বিকল্প দুই আঙুল-বিন্যাসে পাঁচটি উৎসের পরিশ্রম, ভেতর/স্পেসের ওপারের চলাচল, ক্রমের সীমা, Shift, একই কী পুনরাবৃত্তি ও বাদ পড়া একক দেখায়। শুধু প্রশিক্ষণ যোগ্যতা ও ক্রম ঠিক করে; আগে পরীক্ষা করা আলাদা রাখা ফল অনুসন্ধানমূলক তথ্য। অসমর্থিত ক্রমের অংশ সীমায় রাখা হয়, মান বানিয়ে পূরণ করা হয় না। স্কোর যান্ত্রিক মডেল; মাপা গতি বা আরাম নয়।

## আগের পরিশ্রমের চ্যালেঞ্জ

[আগের আলাদা স্টাইলের J1 স্কোরার](../challenge/bangla_dh_challenge.py), [নির্দেশিকা](../challenge/USER_GUIDE.md) ও [তালিকা](../submissions/LEADERBOARD.md) পুরোনো আলাদা সিজন। এগুলো আগের আলাদা বিন্যাসের তুলনা করে, অভিন্ন কাজটি সমাধান করে না।

```powershell
python -m bangla_dh challenge-verify --season legacy-v1 challenge/D-reference.json
python -m bangla_dh leaderboard --season legacy-v1 --check challenge/D-reference.json
```

পুরোনো তালিকা রেফারেন্সের কপিকে জমা হিসেবে নেয় না; স্বাধীন যাচাইকারী স্কোর যাচাইয়ের জন্য নেয়। [পুনরুৎপাদনের নির্দেশনা](REPRODUCE.md) দুই সিজন আলাদা করে। ইনপুট, নীতি বা ক্যালিব্রেশন বদলালে নতুন সিজন লাগে; তালিকা মেশাবেন না।
