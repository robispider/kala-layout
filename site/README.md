# Website source

The bilingual website (Astro + Starlight) is published at <https://robispider.github.io/kala-layout/en/> (English) and `/bn/` (বাংলা), with a language selector that keeps the same page. Its blue research-notebook design leads with evidence and reproducibility, distinct from the green [Kala app and guide site](https://robispider.github.io/kala-releases/en/).

## Edit the content

English content is the Markdown in `docs/`; the Bangla translations mirror it in `translations/bn/docs/`. `scripts/content-map.mjs` lists the pages. `npm run sync` generates the Starlight pages (they are ignored by Git, so edit the Markdown, never `src/content/docs/`). The home page, the leaderboard page and the 404 page are generated by `scripts/sync-content.mjs`; the home page is `src/components/LayoutHome.astro`.

The numbers on the home and leaderboard pages are read at build time from `challenge/challenge-data.json` (the public layouts) and `submissions/leaderboard.json` (challenge submissions); they are never typed by hand. `src/components/ResearchHero.astro` renders the evidence chart and the full portrait mascot without a square image crop. Links to the app's installation, typing and Learn guides follow the reader's language; canonical Markdown uses the English target in both language pairs, localized by `rewriteLinks` at build time.

Links between pages are ordinary relative Markdown links. A link to a file or folder of the repository that is not a page becomes a GitHub link on the website.

## Preview and build

Use Node.js 24 (Node 22.12 or newer is supported by the locked toolchain):

```bash
cd site
npm ci
npm run dev
```

Open the printed address with `/kala-layout/en/` or `/kala-layout/bn/`. `npm run build` first checks that every English page has a Bangla pair with the same links, commands, inline code, headings, steps, list items, table rows, table numbers and key maps, and that every link to a repository file exists. It then builds both languages and checks the generated links, assets, headings, language switching and the search index.

These checks prove structure, not translation quality: ask a native Bangla reader to review the meaning whenever the Bangla changes.

## Publish

In the repository settings choose **Pages → Build and deployment → Source: GitHub Actions**. `.github/workflows/pages.yml` builds from the locked dependencies and publishes pushes to `main`; pull requests are built and checked but not deployed.

The site reuses Kala's mark and Black Bengal goat mascot. Fonts are self-hosted from the Inter and Noto Sans Bengali packages; their licence notices are in `public/licenses/`.
