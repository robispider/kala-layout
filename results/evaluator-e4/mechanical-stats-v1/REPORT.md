# J1 and cross-space movement: complete candidate statistics

**Kala Jhor is the first row. Every subsequent row is a saved candidate, ordered by increasing J1.** This report presents the observed compromise between effort and two cross-space movement measures; it does not combine them into an invented comfort score.

## Definitions and evidence

* **J1:** frozen modeled effort per text unit, including its existing Shift cost. Lower is better.
* **J1 Δ from Jhor:** candidate J1 minus Jhor J1. Both the absolute difference and relative percentage are shown.
* **J1 Δ from previous row:** candidate J1 minus the immediately preceding displayed row. This is the requested running difference, not physical finger travel. It depends on which rows a table includes.
* **Cross-space SF rate:** percentage of valid key–space–key windows whose endpoints use the same finger on different physical keys. Lower is better; same-key repeats are separate.
* **SF distance:** summed key-center distance for those same-finger different-key events, divided by all valid spanning windows. Non-SF windows contribute zero. Units are key-pitch units per window, not total hand travel or measured motion.
* **SF distance Δ:** relative change from Jhor’s SF-distance value; negative means less modeled distance.
* **SF rate + distance improve?:** both values must be lower than Jhor. This flag does not assert improvement in every other movement evaluator.

All numbers use the frozen **model-optimal fingering** and the original **50/50 Wikipedia/newspaper training mix**. Each source is normalized independently. Each vowel style uses its own encoder. Cross-space endpoint coverage is complete. These are corpus-derived point values, not human-trial estimates or statistical confidence intervals.

## Coverage

The completed run saved 26,892 distinct style/layout pairs. The reconstructed nondominated J1/SF-rate union has 246 rows: 153 D and 93 A, including Jhor and Goti. These are the frontiers of saved archives; archive pruning means they are not all visited or feasible layouts. A candidate dominated on J1/SF rate could still differ on another metric, so the full saved collection is also supplied.

26,891 saved rows have both lower cross-space SF rate and lower SF distance than Jhor. None has lower J1 than Jhor. The strict joint J1/movement objective remains unmet.

## Verification and limitations

Every stored permutation was rescored using exact rational J1 and cross-space SF counts, and compared with its saved worker result. Distance uses the frozen geometry in binary64. The distance pair-instance calculation was independently checked against the continuous-window evaluator on reproducibly selected maps of both styles, including the references and every preview candidate. All frontier exports additionally agree exactly with the official challenge scorer. Input, output and original-layout hashes are recorded in this directory’s manifest.

The original Jhor/Goti files and completed run are preserved. Layout copies here are experimental research artifacts. There is no new search, changed model constant, measured typing-speed result, optimality proof or statistical significance claim. Held-out evidence remains in the interpreted report and the balance review; these tables describe training values only.

The earlier Engram interpretation was reversed: **Engram pair and triple-order credit is higher-is-better**. A decrease in its lower-bound score is not an improvement. The J1/SF/count/distance values themselves were correct. The correction is separate from these requested cross-space statistics.
