Generated by `bangla-dh evaluate-phase2`. Machine-readable record: [phase2.json](phase2.json); hashes of every input and output: [run-manifest.json](run-manifest.json).

All Kala data was read in place and never modified. Every generated file is under `colemak-bangla/` (`data/` and `results/`); the code refuses to write anywhere else.

Owner decisions D1–D6 are still open. This phase used the default of each and states where.

## Summary

* **Inventory (D1 default):** 85 placed symbols from Kala's alphabet, validated against Unicode, plus ZWNJ/ZWJ tracked but not placed. ড় ঢ় য় are single units of two NFC code points.
* **Corpus (D4 default):** Bangla Wikipedia, 171,685 train and 19,063 held-out articles (445 M characters after cleaning and deduplication), split by document.
* **Frequencies:** N = 390,391,661 typing units in the training split, space included (14.6 %); 1,898,416 characters outside the inventory (0.48 %).
* **Scorer:** reproduces the analyzer port on all 15 English layouts within 9.8e-09; unit tables, token table and an independent text verifier agree within 7.0e-11 (relative) on the held-out split.
* **NFC round trip:** 454,000 texts (Kala's evaluation word lists and held-out token types) through two key maps, 0 failures.
* **UniJoy baseline (Kala's file):** J0 = 2.1729 on the model-optimal ANSI grid (2.1934 with traditional fingering). Same-finger pairs make up 0.4031 of it. Kala's `bn_bijoy_layout.json` is identical to UniJoy, so there is no separate Bijoy baseline.
* **Context:** a naive frequency-sorted layout scores 1.7081 and a random layout 2.1514; the elementary lower bound for the 90-slot problem is LB0 = 0.9670. These are reference points, not candidates.
* **Decision needed (D2):** under J0 Shift and AltGr are free, so the E1 minimum stacks three symbols on each of the cheapest keys. Without a layer cost (M) a 90-slot optimum is not a usable keyboard; see section 8.

## 2. Typing grammar and the NFC round trip (task 2)

Text is normalized (`bangla-dh-text-v1`: NFC, curly quotes → ASCII, hyphen variants → `-`, U+09F7 → `।`, invisible format characters except ZWJ/ZWNJ removed, whitespace collapsed) and split into units: one code point each, except ড ঢ য + nukta. Independent vowels and vowel signs are different units, hasant is its own unit. A key map turns text into keystrokes with the fewest keystrokes (ties: least key effort), and typing is simulated to decode. Characters a map cannot type are escaped (typed outside the model; they break bigrams). This includes invalid sequences such as hasant directly followed by a vowel sign (a legacy-conversion artifact in a few Wikipedia words): UniJoy's ্ + vowel-sign rule would turn them into an independent vowel, so the encoder never types them with that action.

## 5. Bangla scorer (task 5)

J0 = Σ u_i K(L(c_i)) + Σ_{i≠j} v_ij B(L(c_i), L(c_j)) on the model-optimal ANSI grid (P_d = 1.12, unrounded; every result is repeated on the one-decimal grid). B is the frozen Colemak-DH table including the middle–index benefit (D6 default). Space is a thumb unit with no cost (D2 default); Shift and AltGr cost nothing (M and Q off). For layouts that need several keystrokes per unit, J0 sums all keystrokes and all consecutive keystroke pairs and still divides by the same N, so every layout is scored per unit of the same text.

* **English cross-check:** 15 layouts of the published comparison, `en_books.freq`, each with its own config: largest difference to the analyzer port 9.8e-09 (the port stores frequencies in binary32). PASS.
* **Three routes, bnwiki/heldout, base-layer-first frequency greedy:** unit tables 1.707718539362, token table 1.707718539362, independent verifier 1.707718539482 (N 44,388,875 = 44,388,875). PASS.

## 8. Findings that need owner decisions

* **D2, layer cost.** J0 inherits the original's free Shift. With three free layers the E1 minimum puts three symbols on each of the cheapest keys (the unigram-greedy row above). Only the same-key penalty (2.5) pushes back. A Bangla layout needs M (and probably Q) before a 90-slot search is meaningful; the spec requires them to be measured, not assigned. Options: measure Shift/AltGr timing, restrict v1 to a base layer of 30 symbols plus fixed Shift pairs, or search the base layer under J0 and assign Shift by a separate rule.
* **D1, inventory.** The out-of-inventory table shows what Kala's alphabet lacks, chiefly `.` and Latin text. ZWNJ/ZWJ are tracked but not placed; standard spellings such as র‍্যাব need ZWJ. Digits are placed among the 90 main-block slots in this default; keeping them on the number row would change the scope.
* **D3, fingering.** UniJoy is learned with traditional fingering; it scores 2.1934 on the traditional grid against 2.1729 on the model-optimal grid.
* **D4, corpus.** Phase 2 uses encyclopedic text only; the news cross-check and the mixed search later add news, so domain weights matter.
